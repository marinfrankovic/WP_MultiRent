# MultiRent Companion

MultiRent Companion is the setup and content-management plugin for the **Multi Apartment Rental** WordPress theme.

Use the [MultiRent Complete User Guide](../docs/MULTIRENT_USER_GUIDE.md) for the full site-building workflow, including installation, starter content, Website Setup, Pages & Buttons, rental units, amenities, contact pages, local pages, menus, backup, deployment, Mermaid process diagrams, and Draw.io diagram files.

This README is kept only as a short plugin reference and as the source for **MultiRent Setup > Help / README** inside WordPress admin.

## What The Plugin Adds

- **Website Setup**: property name, tagline, logo, homepage sections, hero content, global font, colors, stats, reviews, top menu builder, and starter content.
- **Pages & Buttons**: up to three apartment pages, up to three contact pages, per-slot top-menu visibility, and homepage hero buttons with page dropdown destinations.
- **Rental Units**: apartment, room, villa, or rental listing management with images, details, amenities, maps, QR images, video URLs, and page assignment.
- **Local Page**: local guide content, highlights, activities, useful links, templates, and visibility settings.
- **Amenities**: reusable feature labels used on rental-unit cards and detail pages.
- **Demo Content**: link to the hosted public demo without importing large sample media.
- **Help / README**: this short reference inside WordPress admin.
