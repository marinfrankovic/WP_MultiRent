WordPress theme and companion plugin

Build a rental property website without editing theme files.

MultiRent is a private-use, no-code WordPress package for apartments, rooms, villas, and multi-unit holiday rentals. Manage listings, galleries, amenities, maps, QR codes, contact details, local guides, branding, colors, and menus from WordPress admin.

Everything a small rental site needs in one focused package.

MultiRent keeps the public site clean while giving owners practical controls inside WordPress admin.

Rental unit management

Create apartments or rooms with capacity, bedrooms, bathrooms, size, price note, booking link, amenities, gallery images, QR code, map, and optional video.

Website setup screens

Edit property name, tagline, page logo, homepage hero, global font, intro text, stats, reviews shortcode, colors, and header menu links.

Ready page roles

Assign and configure Apartments, Contact, and Local Guide pages with templates, preview buttons, and visibility controls.

Guest-ready details

Show booking instructions, local highlights, activity cards, useful links, contact QR code, maps, and clear inquiry paths.

Starter content and hosted demo

Create starter pages, amenities, and rental units for this site, or open the hosted public demo for a complete preview without importing sample media.

Simple packaging

Install the theme ZIP first, then the companion plugin ZIP. The release also includes an extract-first package containing both.

Preview the public experience.

The theme is built for compact rental information, fast scanning, and clear paths from apartment details to inquiry.

Quick install workflow.

Use the packaged ZIP files from the latest GitHub release. Upload the theme and plugin separately in WordPress admin.

Download release ZIPs

Get the theme upload ZIP and companion plugin upload ZIP from the latest release.

Install the theme

Open Appearance, upload the MultiRent theme ZIP, then activate Multi Apartment Rental.

Install the plugin

Open Plugins, upload and activate MultiRent Companion, then go to MultiRent Setup.

Create content

Create starter pages or optional demo content, then replace examples with real rental details.
