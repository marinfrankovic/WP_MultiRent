# MultiRent Diagram Files

This folder contains Draw.io diagram files for the MultiRent documentation.

- `MULTIRENT_PROCESS_DIAGRAMS.drawio`: multi-page Draw.io file with graphical workflow diagrams for the main user processes.
- `MULTIRENT_WORKFLOW.drawio`: single-page overview workflow diagram.

The full written guide with Mermaid diagrams is here:

- [MultiRent Complete User Guide](../MULTIRENT_USER_GUIDE.md)

## Diagram Pages

`MULTIRENT_PROCESS_DIAGRAMS.drawio` contains:

1. Overall Build Flow
2. Website Setup
3. Apartment Pages
4. Contact Pages
5. Rental Units and Amenities
6. Local Page
7. Hero Buttons and Menu
8. Backup and Deploy

The guide itself contains in-text Mermaid diagrams for every workflow, including starter content, rental units, amenities, local page setup, hero buttons, top menu, testing, backup, and deployment.
