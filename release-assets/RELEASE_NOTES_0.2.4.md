Customizer and Website Setup enhancement:

- Add a **Hero eyebrow** field to MultiRent Setup > Website Setup, directly above Hero Title, so the small uppercase label above the homepage headline can be edited without code. It is also available in Appearance > Customize > MultiRent Home.
- Existing sites are unaffected: the field defaults to the previous "Multi-unit rental website" text, so the homepage looks identical until you change it. Leave it empty to hide the label.

Upload guide:

- `multirent-theme-upload-0.2.4.zip` — Appearance > Themes > Add New > Upload Theme
- `multirent-companion-plugin-upload-0.2.4.zip` — Plugins > Add New > Upload Plugin
- `multirent-complete-package-extract-first-0.2.4.zip` — extract first; contains both upload ZIPs

Tested with WordPress 7.0; requires PHP 8.4 or newer.
